AtomVM の公式リポジトリには、明確なコーディングスタイルが定義されています。

https://doc.atomvm.org/latest/CONTRIBUTING.html#coding-style

言語ごとの方針は次のとおりです。

- Erlang: [erlfmt](https://github.com/WhatsApp/erlfmt) を使う
- Elixir: [mix format](https://hexdocs.pm/mix/main/Mix.Tasks.Format.html) を使う
- C言語: [clang-format-16](https://releases.llvm.org/16.0.0/tools/clang/docs/ClangFormat.html) を使う

C言語用には基本的なルールの解説に加え、各リポジトリに`.clang-format` が用意されています。

https://github.com/atomvm/AtomVM/blob/main/.clang-format

自分の参加する AtomVM 関連プロジェクトでも同じスタイルを使いたいので `.clang-format` をそのままコピーしています。

```bash
curl -o .clang-format https://raw.githubusercontent.com/atomvm/AtomVM/main/.clang-format
```

https://github.com/piyopiyoex/hello_atomvm_nif

あとは`clang-format`任せます。

```bash
clang-format -i nifs/*.c
```

これで自前の NIF のコードでも、AtomVM 本体と同じ雰囲気に揃います。
